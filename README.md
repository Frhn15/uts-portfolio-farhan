## 1. Deskripsi

Website portofolio pribadi yang dibuat menggunakan HTML5, CSS3, dan JavaScript. Tampilan diawali dengan halaman opening. Tombol **Jelajahi Profil** akan membuka halaman profil lengkap.

## 2. Komponen yang sudah disediakan

- Struktur dokumen dan elemen semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Opening screen dengan tombol interaktif untuk masuk ke profil.
- Header dan navigasi antarbagian.
- Biografi dan profil utama.
- Tabel riwayat pendidikan.
- Tabel riwayat pengalaman kerja.
- Daftar keahlian menggunakan unordered list.
- Bagian proyek aplikasi warga RT 011 RW 002.
- Elemen multimedia audio dan video.
- Form kontak dengan validasi HTML dan JavaScript.
- Styling CSS responsif untuk desktop, tablet, dan ponsel.
- Tombol pergantian tema gelap/terang, menu mobile, animasi reveal, dan tombol salin email.

## 4. Cara menjalankan

1. Ekstrak file ZIP.
2. Buka folder proyek.
3. Klik dua kali `index.html`, atau jalankan menggunakan ekstensi **Live Server** di Visual Studio Code.
4. Klik tombol **Jelajahi Profil** pada halaman opening.
5. Uji navigasi, tombol tema, pemutar audio/video, dan form kontak.

Website ini tidak membutuhkan instalasi framework atau database untuk dijalankan sebagai halaman statis.

## 5. Data profil yang digunakan

Data biografi, pendidikan, pengalaman kerja sebelumnya, nomor telepon, dan email diambil dari CV yang diberikan. Informasi pekerjaan saat ini, tanggal lahir, daftar skill web, dan proyek aplikasi warga ditambahkan berdasarkan keterangan pengguna.

Alamat rumah lengkap tidak ditampilkan pada halaman publik; bagian domisili hanya menampilkan Bekasi Timur, Kota Bekasi.

## 6. Catatan sebelum pengumpulan

- Ganti teks `NIM` pada nama folder dengan NIM mahasiswa yang sebenarnya.
- Pastikan nama, data, dan kontak sudah benar.
- Ambil screenshot halaman opening dan halaman profil setelah tombol **Jelajahi Profil** diklik, lalu simpan ke folder `screenshots/` untuk melengkapi laporan pengumpulan.
- Jika aplikasi warga memiliki fitur spesifik, tambahkan deskripsi fitur dan tangkapan layar asli pada bagian Proyek. Gambar `images/imagelain.jpg` saat ini hanya ilustrasi visual, bukan screenshot aplikasi.
- Form kontak menggunakan `mailto:`. Pesan akan diteruskan melalui aplikasi email pengguna dan tidak disimpan di server.
- Audio dan video perkenalan disertakan sebagai contoh elemen multimedia lokal.
